\# Loan Approval Prediction using Explainable AI



\## Project Overview



This project uses machine learning algorithms to predict whether a loan application will be approved or rejected. It also uses Explainable AI techniques to understand the factors influencing predictions.



\## Objectives



\- Predict loan approval status.

\- Perform data preprocessing and exploratory data analysis.

\- Train and compare multiple machine learning models.

\- Evaluate model performance.

\- Explain predictions using SHAP.

\- Develop an interactive application using Streamlit.



\## Dataset



The dataset contains 4,269 records and 13 original columns.



Target variable: loan\_status



Classes:

\- Approved

\- Rejected



Dataset file: data/loan\_approval\_dataset.csv
